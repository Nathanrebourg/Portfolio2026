# Portfolio 2026 — Nathan Rebourg

Site statique personnel hébergé avec Sites. Le dossier `dist/` contient les pages, la feuille de style et les scripts partagés.

- Accueil : `dist/index.html`.
- Pages projet : NRclip, Liaison, Anyme Rediffs et portfolio.
- Biographie : `dist/pages/a-propos.html`.
- Les anciennes pages académiques et leurs captures dédiées ont été retirées.
- NRclip comporte une vidéo de démonstration ; Liaison présente des aperçus anonymisés.
- Le formulaire conserve le service Formspree déjà utilisé par le site.

Aperçu local : `python3 -m http.server 8765 --directory dist`.

Site public : https://nathan-rebourg.greybead8193.chatgpt.site

Le dossier `dist/` peut être servi par un hébergeur statique indépendant. Les formulaires utilisent Formspree ; aucun serveur applicatif n’est nécessaire.
